{# Cellule "titre" commune aux 3 vues (Torrents/Séries/Films) : le libellé lui-même, la jaquette au survol et les liens externes/arr. Un seul macro plutôt que le même bloc recopié trois fois — c'est aussi ce qui garantit que les trois vues se comportent pareil au survol. `meta` vaut None quand il n'y a rien à rattacher (torrent jamais importé, ou fichier bibliothèque supprimé) : on retombe alors sur du texte nu. data-poster porte l'URL interne, PAS un déjà dans le HTML : clearr.js ne charge l'image qu'au premier survol de la ligne (45 jaquettes × ~20 Ko seraient sinon téléchargées à chaque rendu de la page, alors qu'on en regarde une ou deux). #} {# `details_url` rend le libellé cliquable : il ouvre la fiche détail dans la modale (même mécanique data-get/#modal-body que les écrans de confirmation, donc aucun JS à ajouter). Les 3 vues en fournissent une, enfants cross-seed compris — ce sont de vrais torrents, avec leur propre tracker, leur propre ratio et leurs propres fichiers. Laisser le paramètre vide retombe sur du texte nu. #} {% macro title_cell(text, meta, links=True, text_class='', details_url='') %} {%- set poster_attrs %}{% if meta and meta.poster %}data-poster="{{ meta.poster }}" data-poster-title="{{ meta.title }}"{% endif %}{% endset -%} {%- if details_url %} {{ text }} {%- else %} {{ text }} {%- endif %} {%- if links and meta %}{% for l in meta.links %} {{ l.label }} {%- endfor %}{% endif %} {% endmacro %}
